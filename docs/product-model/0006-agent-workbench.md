# Agent 工作台

状态：已接受。Modelry 内置 Agent 与 MCP 使用同一套工具、权限、执行策略和审计。

Agent 是受控客户端；不拥有 SQLite、Shell 或任意 HTTP 执行旁路。业务工具覆盖集合、记录、结构、访问规则、应用认证、Hooks、Webhook、事件触发、任务及观察。身份、凭据、备份、恢复和运行时管理不开放为工具。

每个内置 Agent / MCP 服务账号具有独立执行策略：只读、写入需确认、普通写入自动。默认写入需确认。工具操作许可与执行策略相交，不因 Owner 批准提升服务账号权限。删除、应用、丢弃、启用、外部执行及启用中的自动化修改必须确认。

数据授权按会话记录集合、字段范围；默认单次读取最多 20 条。模型服务、模型名称及加密密钥由 Owner 在设置中管理。外部 MCP 的模型仍由外部客户端管理。

任务、步骤、待确认操作和审计必须耐久保存。确认固定操作和目标快照；重复确认不重放，重启中断任务和执行中的步骤。外部副作用不能描述为可回滚事务。


### Agent 与 MCP 统一页面（2026-10-05）

一级导航统一为 Agent（`/agent`），默认打开工作台，集中展示内置 Agent 和外部 MCP 的会话、待确认操作及执行历史。`/agent?tab=mcp` 仅展示 MCP 接入命令、连接信息、服务账号及权限配置入口，不重复展示执行历史。页签切换保留当前会话；模型设置仍由 Owner 在 `/settings/agent` 管理。旧 `/mcp`、`/connect/mcp`、`/settings/mcp` 深链接保留查询参数并重定向到 MCP 配置页签。两入口共用的工具、权限、审批和审计规则不变。
