# ADR-0009：内置 Agent 与 MCP 的共享执行层

状态：已接受。

将 CLI 中的 MCP 业务目录、参数校验与正式 API 映射移动到 `internal/agenttools`。新增 `internal/agent` 负责权限策略、会话、任务、确认和模型调用。两个入口均调用同一受控执行层，执行层调用已有正式 API 路由与领域服务，不直接修改业务 SQLite 表。

业务许可复用 `internal/permissions`，补充 Hooks / Webhook / 事件触发 / 任务权限。MCP 通过服务账号认证调用 Agent 端点；策略与批准管理仅 Owner 可用。审批保存发起身份，不借用确认者的业务权限。

Agent 状态使用项目 SQLite；模型密钥复用项目 AES-GCM Secret 存储。模型请求在事务外执行。开始执行前耐久声明步骤，结果不确定时标记中断，不重试写入。

现有 MCP 工具名称和参数保持；默认写入从直接执行改为返回待确认操作，属于有意的兼容性变化。CLI 人工管理命令与现有 Admin / HTTP 操作不受影响。

共享执行层的目标复核与写入持有运行时业务写入门，人工 HTTP 写入及权限撤销不能在复核与调用之间插入。批次在同一门内逐项执行并记录结果，不扩展为数据库回滚承诺；后台已开始的投递不被回滚。
