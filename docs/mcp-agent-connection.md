# MCP 与内置 Agent 接入

## 本次兼容性变化

MCP 的业务工具名称和参数保持不变，58 项工具与内置 Agent 共用正式领域 API。新增 Hooks、Webhook、事件触发、定时任务、应用认证及执行历史能力。CLI 与人工 Admin 页面保持原有执行方式。

**MCP 默认写入改为等待 Owner 确认。** 客户端需要处理 `approvalRequired`、`operationId` 与 `reviewUrl`，不能把提案成功描述成业务已执行。通过 `agent_operation_get` 查询实际结果，通过 `agent_session_get` 取得会话；只有 `succeeded` 代表成功。拒绝、目标变化或权限撤销需重新提出具体操作，不能自动重试结果不确定的写入。

在服务账号详情设置操作许可和执行策略。普通写入自动仍与服务账号自身权限相交；只读账号不能通过 Owner 确认获得写权限。删除、结构或规则应用、认证配置应用、启用自动化、修改启用中的配置、任务执行、Webhook 测试和重试始终需要单独确认。批次仅覆盖 Owner 看见并选中的固定普通操作清单。

## 外部智能体配置

```json
{"mcpServers":{"modelry":{"command":"modelry","args":["mcp","--api-url","http://127.0.0.1:8080"],"env":{"MODELRY_API_KEY":"<仅在客户端环境中填入服务账号密钥>"}}}}
```

请按 `modelry mcp --help` 使用当前版本的参数。外部客户端自行配置模型；Modelry 的「设置 → Agent 与模型」仅影响内置 Agent。

示例指令：先检查集合与模型，提出新增集合或字段的具体方案；收到 `approvalRequired` 时显示审核链接并等待 Owner。批准后查询操作状态，成功再读取模型验证，失败则报告每项已完成事实。读取业务记录前，Owner 必须在对应会话授权集合与字段，单次最多 20 条。

## 内置 Agent

顶栏 Agent 或 `/agent` 打开会话。Owner 在 `/settings/agent` 保存兼容模型 API 地址、模型和可选密钥，测试保存的连接。密钥加密保存、只写入，不返回给界面或进入会话历史。运行中的任务固定启动时的配置，新配置用于下一次任务。

业务记录原始读取结果只在当次模型回合内使用，不持久化到聊天步骤。刷新恢复状态；重启把运行任务标记中断，不重放写入。停止阻止后续调用，已完成结果保留，外部副作用不承诺回滚。


### Agent 与 MCP 统一页面（2026-10-05）

一级导航统一为 Agent（`/agent`），默认打开工作台，集中展示内置 Agent 和外部 MCP 的会话、待确认操作及执行历史。`/agent?tab=mcp` 仅展示 MCP 接入命令、连接信息、服务账号及权限配置入口，不重复展示执行历史。页签切换保留当前会话；模型设置仍由 Owner 在 `/settings/agent` 管理。旧 `/mcp`、`/connect/mcp`、`/settings/mcp` 深链接保留查询参数并重定向到 MCP 配置页签。两入口共用的工具、权限、审批和审计规则不变。
